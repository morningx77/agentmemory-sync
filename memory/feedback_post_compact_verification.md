컴팩션된 대화를 이어받아 작업을 재개할 때는 반드시: ① 요약 속 문구·앵커·구조로 추측 편집 금지(편집 전 실파일 Read/Grep 재확인) ② 컴팩션 전후 실행된 편집(전역 치환·위치 추정 삽입·요약 기반 신규 생성)을 실파일 대조로 전수 재검증(미치환 잔존 grep 포함) ③ 검증 결과를 사용자에게 명시 보고 ④ 요약≠실파일이면 실파일이 정본.

**Why:** 260810 실사고 — v0.33.0 태그 전환 배치 중 컴팩션 발생. 요약 기억으로 "그룹을 지워도"를 앵커로 치환(실제는 "그룹을 삭제해도" → 미치환), 마크업 위치를 추정해 병합 제안 행을 안내 문구 div **안에** 오삽입, both-sides 태그 행 누락. div 균형 검증만으론 못 잡는 유형(문구 미매칭·중첩 오류는 균형이 맞음).

**How to apply:** 루트 `260610_ISPARK/CLAUDE.md` §"컴팩션 후 재개 검증 절차"(260810 등재)가 정본. 컴팩션 요약으로 세션이 이어졌음을 인지한 즉시 이 절차를 자동 발동한다 — 사용자가 요구하기 전에. [[compact-kickoff-doc]] (컴팩트 전 킥오프 지시서)와 쌍: 전=킥오프 문서화, 후=재개 검증.
