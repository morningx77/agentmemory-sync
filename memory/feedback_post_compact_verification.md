컴팩션된 대화를 이어받아 작업을 재개할 때는 반드시: ① 요약 속 문구·앵커·구조로 추측 편집 금지(편집 전 실파일 Read/Grep 재확인) ② 컴팩션 전후 실행된 편집(전역 치환·위치 추정 삽입·요약 기반 신규 생성)을 실파일 대조로 전수 재검증(미치환 잔존 grep 포함) ③ 검증 결과를 사용자에게 명시 보고 ④ 요약≠실파일이면 실파일이 정본.

**Why:** 260810 실사고 — v0.33.0 태그 전환 배치 중 컴팩션 발생. 요약 기억으로 "그룹을 지워도"를 앵커로 치환(실제는 "그룹을 삭제해도" → 미치환), 마크업 위치를 추정해 병합 제안 행을 안내 문구 div **안에** 오삽입, both-sides 태그 행 누락. div 균형 검증만으론 못 잡는 유형(문구 미매칭·중첩 오류는 균형이 맞음).

**How to apply:** 루트 `260610_ISPARK/CLAUDE.md` §"컴팩션 후 재개 검증 절차"(260810 등재)가 정본. 컴팩션 요약으로 세션이 이어졌음을 인지한 즉시 이 절차를 자동 발동한다 — 사용자가 요구하기 전에. [[compact-kickoff-doc]] (컴팩트 전 킥오프 지시서)와 쌍: 전=킥오프 문서화, 후=재개 검증.

**★⑤ 요약은 「사용자가 무엇을 말했나」도 지어낸다** (260909 추가 · 저널 4660 vs마스터). 위 ①~④는 **편집 대상 재확인**만 덮고 **사용자 발화 인용**은 안 덮는다 — 그 공백이 실제로 터졌다. vs마스터가 컴팩트 요약에 따옴표로 실린 「사장님 지적 2문장」을 사실로 삼아 자수하고 킥오프·메모리에 박았는데, 트랜스크립트 전 기간 2,993건 실측 결과 **두 문장 다 0건**이었다.

**Why:** 사용자 발화는 **최고 권위 근거라 아무도 검증하지 않고**, 따옴표 형태로 오면 원문처럼 보인다. 그것으로 규율·승격·메모리를 만들면 **거짓이 제도가 된다**. 잘못된 것은 처리가 아니라 **자기 진단**이었다.

**How to apply — ★규율이 역할별로 갈린다**(4663 ② · 내 조항이 워커에게 실행 불가였다). **나는 워커다.** ⓐ 컴팩트 요약 속 사용자 인용을 근거로 쓰지 마라. ⓑ ★**워커에게 「사장님」은 거의 전부 마스터의 전언이다**(vs스토리북2 실측 = 자기 세션의 그날 사용자 발화 **2건**). 트랜스크립트는 내 것이 아니라 **못 연다** — 그러니 ⓒ **구분이 없으면 청구한다**: 「이게 원문입니까 해석입니까」. **그건 의심이 아니라 규약이 요구하는 확인이다.** ⓓ 워커도 열 수 있는 대조 소스 **둘** = **저널의 「사장님 원문」 블록** · **코드 주석**(원문이 박혀 있는 자리가 많다). ⓔ 못 찾으면 「사장님이 말씀하셨다」가 아니라 **「요약에 그렇게 적혀 있다」**로 쓴다. ⓓ 단정도 하지 마라 — 「없다」가 아니라 **「이 세션 트랜스크립트 텍스트에는 없다」**(이미지·타 세션은 내가 못 본다). 큐 `FU-312`. [[no-unverified-as-fact]]와 쌍.


**★전언 체인엔 검증 장치가 없다** — 게이트도 git 도 라이브도 「사장님이 그렇게 말씀하셨나」를 묻지 않는다. 마스터가 전언을 틀리면 워커 전원이 틀린다(260909 실증: 요약이 지어냄 → 마스터가 사용자 보고에 씀 → vs스토리북2가 자기 저널에 옮김). **내 실증(260909)**: 내 킥오프 §1의 「판정 한 줄 = …애매하면 ag」를 「사장님 확정·저널 4249」 아래 적어 뒀는데, 대조하니 ⓐ 출처가 4249가 아니라 **vs마스터 4246 + ag마스터 4247**이고 ⓑ **사장님 원문이 아니며** ⓒ **이미 4294로 폐기된 규칙**이었다. 다음 세션이 그대로 읽었으면 「애매하면 내가 받는다」로 움직여 **사장님 지시에 역행**했다. **귀속을 모르면 귀속하지 않는다 — 「못 쟀다」로 쓴다**(4249 ② 승격).
