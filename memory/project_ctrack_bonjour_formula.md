C트랙(네이버 imgsrc_ 방송리뷰)의 레퍼런스 `hanbbogga_`(봉쥬르매거진) cat64 164편 전수+정독 11편으로 생성 공식을 확정했다(2026-08-30, 페이블 세션).

- **목적 = 전수 재현, 조회수는 결과** (사용자가 하루 종일 세 번 지적한 끝의 최종 정의).
- **유형은 미리 고르지 않는다 — 영상이 정한다**: ①마디 수 ②장(章)으로 서나/하나의 흐름인가 ③전체인가 한 장면인가 → 소제목형 27% / **리드문장형 57% 주력** / 단신형 16%. 마디 수 가설(5+=Ⓐ)은 반증됨 — B6(이호선 5,857자)은 마디 8개인데 소제목 0.
- **Ⓑ의 마디 장치 = 리드 문장**(「문제의 시작은 남편의 주식 투자였습니다.」류 한 문장 전환 문단, 92편 중 75%+).
- **소감 본형 = 재해석**(「A라기보다 B에 가까워 보였습니다」, 상위 10편 전 편) — 감정 보고 아님.
- 문체 이분포: 산문체 71%(최근 주력·기본값) / 단문체(행갈이) 29%. 20~39자/문단 구간이 비어 완전 분리.
- 제목 훅도 유형 연동: 따옴표 시작 Ⓐ18% / Ⓑ78% / Ⓒ93% — 「따옴표 시작 금지」는 유형 교란이었음. 훅 부품 3칸(아이 피해+2차 타격+사실 머리)은 **천장 예측기**로만 유지.
- **구 「소제목 5.0배 최강」도 유형 교란** — 전수 71%가 소제목 0개.

**Why**: 상위 몇 편만 보고 일반화한 규칙들이 게이트가 되어 회차를 계속 기각했다(C8 「5마디 미만 기각」). 봉쥬르는 회차를 버리지 않고 형태를 바꾼다.

**채점기·게이트도 골격별 재교정 완료(260830-2)**: `c_score.py` 임계=골격별 p25·규격=p10~p90·축 2개 신설(리드 문장·재해석), **`--calib` 목적을 「변별력」→「원문 통과율」로 전환**. `gate_check.py --track C` 골격 인지형 + Bc10(재해석) 신설. 전수 교정 = `tools/calib_ctrack_all.py`(구 `calib_ctrack.py`는 10편만 봤다). 결과: c_score must 축 원문 70%+, 게이트 전 골격 균일 70%·상위 5편 5/5.

★재교정에서 잡은 결함 3건 — ①임계가 상위 3편 기준(원문 11~36%만 통과) ②`anti`의 「0개 금지」가 `저는`에도 걸려 원문 32% 오반려(0회가 정상) ③**Bc5가 `split_sentences` 대신 자체 분할**해 단문체 원문 78% 오반려(gate_check 자신이 경고한 함정의 재발 — 측정기는 하나로 통일).

★정정: 「리드 문장 = Ⓑ의 표지(75%)」는 부분 오류였다. 전 골격 공통 장치(80/85/70%)이고, Ⓑ의 특징은 **「소제목 없이 그것만으로 끊는다」**이다. 원인 = Ⓑ만 재고 다른 골격을 안 쟀다([[feedback_partial_response_is_not_absence]]).
