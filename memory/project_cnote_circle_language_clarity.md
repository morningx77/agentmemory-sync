CNOTE 원(circle) 시각언어를 컴포넌트/템플릿에 적용할 때 반복된 "명료성 부족" 피드백의 근본 원인과 해법. 정본 가이드 [[project-cnote-dynamiclayer-library]]와 별개인 CDS 원 언어 전용 교훈.

**핵심 원리**: 원을 규칙 없이 흩뿌리면(배치) "우연"으로 보이고, **명시적 기하 규칙으로 조립하면 "필연"**으로 보인다. 이 언어의 대전제("우연이 아니다")는 배치 방식 자체가 규칙을 증명할 때만 성립한다. = 명료성의 정체.

**배치 규칙 4종 (흩뿌림 금지)**: ①접선(tangent, 원 가장자리 맞닿음·간격을 크기에 종속) ②동심(concentric, 같은 중심·등간격 반지름) ③방사대칭(radial, N개를 360/N° 등각) ④등간격·패턴(grid, 균등간격+하이라이트는 행/열/대각/순서).

**실패 모드 → 수정 규칙 (실전 검증)**:
- 무작위 산포(큰 원 안 작은 원 임의배치) → **방사대칭 등각**(AvatarGroup 72°)
- 어중간한 리듬(크기↓+간격 균등) → 크기 고정·**opacity만 점층**(Timeline 100/55/30%) 또는 접선으로 간격을 크기에 종속
- 무작위 하이라이트(grid-dot 랜덤) → **완료 N개 순서대로 채움** 패턴
- 원이 장식 전락 → 원을 **크고 밀도 있게**(주인공)
- 눈대중 기하 → 좌표를 **규칙으로 계산**(72° 등각·tangent 체인)

**리듬 규칙**: 순수 반복(동일) 또는 깔끔한 점층(등비/등차) 둘 중 하나. "크기는 줄면서 간격은 균등" 같은 중간 상태 금지.
