CNOTE 디자인 진행 = **3단계**: ① 컴포넌트 디자인(정본 기준 재작업 · ActionCard·PersonCard 완료 · 9종 재설계 진행) → ② 화면 미드파이 **baseline 초안**(AI가 47화면 전체 컴포넌트 조립) → ③ **크리에이티브 협업**(사용자가 핵심 3영역 고도화).

**역할**: AI=47화면 전체 baseline 초안(개발 우선 전달 목적). 사용자=크리에이티브 3영역 고도화(초안 위에).

**화면 분류**: 🎨크리에이티브(AI초안=출발점→사용자 발전)=`01 온보딩`·`03 홈`·`02 미팅흐름 中 녹음+정리결과`. ⚙️기능(AI초안=최종근접→개발전달)=나머지(사람·소통·비서·통제·설정·할일·위젯·캘린더·알림검색·미팅나머지).

**초안 방식 2분**: 기능=완성도 높게(바로 개발). 크리에이티브=발전여지 남긴 baseline(구조·컴포넌트 정돈하되 비주얼 열어둠).
