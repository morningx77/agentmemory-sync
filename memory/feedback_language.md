모든 응답, 설명, 대화는 반드시 한글로 작성한다.

**Why:** 사용자가 명시적으로 요청함 — "앞으로 모든 대화와 설명은 한글로 진행해줘"

**How to apply:** 코드 주석, 커밋 메시지 등 기술적 결과물이 아닌 모든 사용자 대면 텍스트는 한글로 작성. 코드 자체는 영어 관례를 따름.
