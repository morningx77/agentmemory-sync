JSX 주석은 **자리에 따라 형태가 다르다**.
- **자식 자리**(태그와 태그 사이) = 반드시 `{/* ... */}`. 중괄호 없는 `/* */` 는 **텍스트 노드**가 되어 화면에 찍힌다.
- **식 자리**(`{cond && (` 바로 뒤 · `return (` 바로 뒤 · 속성 사이) = `/* ... */`. 여기에 `{/* */}` 를 넣으면 **빈 객체 리터럴**이라 구문 오류다.

**Why:** 260909 하루에 세 번 냈다. ③은 자식 자리 중괄호 누락이라 tsc·게이트·gate:render 를 전부 통과했다. **260914 네 번째는 반대 방향이다** — `{sheet === 'memoEdit' && (` 바로 뒤, `<BottomSheet` 윗줄에 `{/* */}` 를 3곳 넣었다. Vite 변환이 실패해 공유 개발 서버에서 page-scr-person 전 스토리가 404 가 됐고(약 10분), 다른 창(ag기획)의 type-check 가 먼저 적색으로 잡았다. 이번에도 원인은 편집 스크립트 헬퍼 한 개가 넣을 자리를 가리지 않은 것이다.

**How to apply:** ⓐ 주석을 넣을 줄 **바로 윗줄 끝이 `(` 나 `&&` 면 식 자리** → `/* */`. 윗줄이 닫힌 태그·텍스트면 자식 자리 → `{/* */}`. ⓑ 편집 스크립트가 여러 곳에 주석을 뿌리면 **자리마다 형태를 따로** 정한다. ⓒ 편집 직후 **바뀐 파일마다 `npx esbuild <파일> --loader:.tsx=tsx`** 로 파싱한다(수 초) + `npm run type-check`. 자식 자리 누락은 파싱도 통과하므로 렌더 글자 확인이 따로 필요하다. ⓓ ★`tsc -p .` 는 빈 검사다 — [[storybook-tsc-p-dot-empty]].
