★260814 크리에이티브 세션. `SCR_NOTE_RESULT`(미팅 정리 결과 = **저장 전 검수** 화면)를 **분절 카드 스택 → AI가 저술한 한 편의 리포트**로 재설계, **컨셉 확정**(사용자). ★실행(mid-fi 정본 역반영·device)은 **미착수 · 별도 배분** — 크리에이티브는 정본·device·후속큐를 **건드리지 않았다**.

**확정 3변경**
1. **히어로 → 리포트 마스트헤드 승격** — 성공 토스트("✦AI가 만남을 관계로 정리했어요") 폐기, 컬러 면에 **상태마크+제목+인물행+메타1줄+요약+`원본`칩**. → **FU-92 닫힘 제안**(device-only 히어로를 정본에 역반영, FU-13 선례).
2. **관련 인물 섹션 폐기 → 마스트헤드 주어로 통합**(단일 출처). → **FU-93 닫힘 제안**(선택지 ⓐⓑⓒ 아닌 **ⓓ 통합** 신설). ★근거 = 정본 1018행 주석이 이미 *"인물 행의 sub로만 표기(단일 출처)"* 천명.
3. **전체 스크립트 펼침 → `원본` 소형 칩 + 시트 오버레이**. ★사용자 지적 *"원본이 10~20배면?"* 로 **설계를 뒤집음: 아카이브 우선 → 근거 우선** — 시트 기본 뷰 = **`요약 근거 N`**(주장별 원문 발췌·타임스탬프, 스크롤 노동 0), `전체 기록 N` 세그먼트 + **[다음 근거 ↓] 점프**. 복귀 = 하단 풀폭 [리포트로 돌아가기]. → **FU-91 근본 해소**(토글 계약 소멸, NOTE_RESULT 한정) · **FU-90 확대**(NOTE_DETAIL도 방식 통일 필요).

**불변 규칙(실측)**: ⓐ**personal은 제목 없음** — "없는 제목을 지어내지 않는다 · 없으면 본문이 그 자리를 대신"(정본 827~828) → 마스트헤드에 **제목 없는 변형** 필수 ⓑIBMS2 판정 **4형태**(ON / OFF-신규거래처 / OFF-무신호 / 행없음), ★**sales-new-customer는 OFF가 정본**(v0.56.1 정정·ON 금지), ★**OFF엔 행선지 줄 없음** ⓒ강등은 시각 격만, **근거·되돌리기 기능 유지** ⓓ카드=경계(단일 박스·세로바 1개) ⓔ골드 1점 = **다음 일정(타이밍)**.
